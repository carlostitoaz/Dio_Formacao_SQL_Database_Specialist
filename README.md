# 🗄️ Formacão SQL Database Specialist

Este repositório reúne os principais projetos e desafios desenvolvidos ao longo da Formacão SQL Database Specialist, com foco em modelagem, manipulação e administração de bancos de dados relacionais.  
Durante o curso, aprofundei meus conhecimentos em modelagem conceitual, DDL/DML (SQL) e boas práticas de projeto de banco de dados, além de aplicar técnicas de recuperação e controle de concorrência.

---

## 🚀 Habilidades Desenvolvidas

- Modelagem de bancos de dados relacional e conceitual (MER e DER)
- Criação e manutenção de tabelas, chaves primárias e estrangeiras
- Uso de DML (Data Manipulation Language) para inserir, atualizar e consultar dados
- Uso de DDL (Data Definition Language) para definir e estruturar bancos de dados
- Aplicação de boas práticas de normalização
- Criação de consultas otimizadas (SQL)
- Entendimento de controle de concorrência e recuperação de dados
- Desenvolvimento de projetos práticos com modelagem e scripts SQL

## 🎓 Sobre a Formação

A Formacão SQL Database Specialist foi projetada para desenvolver habilidades essenciais em banco de dados, abordando desde o planejamento e modelagem até a manipulação e controle de concorrência.  

O conteúdo abordou:
- Modelagem de dados conforme regras de negócio
- Criação de estruturas relacionais otimizadas
- Aplicação de comandos SQL para manipulação e consulta de dados
- Práticas de normalização e integridade referencial
